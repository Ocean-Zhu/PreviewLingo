# Security

Never include API keys, private PDF text, Keychain exports, credentials, or personal diagnostic dumps in an issue or pull request.

To report a vulnerability, use this repository's private vulnerability-reporting feature when available. Otherwise open a minimal issue requesting a private contact without disclosing exploit details or secrets.

Build locally to inspect the source and dependency-free request construction. Community downloads are ad-hoc signed unless a release explicitly states that it is notarized. Validate download checksums against the release's SHA256SUMS.txt.

Provider keys and model access are supplied by the user. Custom endpoints receive the text explicitly submitted for translation. Use endpoints you trust.
