# App Icon

AppIcon.png is original project artwork generated with the built-in image-generation tool for PreviewLingo, and distributed with the project under the MIT license. It is not copied from Apple's Preview icon.

Generation prompt:

> Create an original native macOS icon for PreviewLingo, a PDF text translation companion for Apple Preview. Reference document inspection and an optical lens, without reproducing Apple's icon. Use a white porcelain rounded-square tile, overlapping sky-blue and white paper sheets with dark teal text strokes, and a turquoise/indigo magnifying lens containing an A/文 translation symbol. Orthographic front view, crisp edges, restrained native depth, transparent background, generous padding, no wordmark, no watermark, no camera imagery, and no Apple trademarks.

The build script uses macOS sips and iconutil to generate the standard multi-resolution ICNS resource from this PNG.
